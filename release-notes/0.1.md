# Iman 0.1

First release of Iman.

- Reliable prayer and pre-prayer reminders, with a sound choice for each prayer (Default, Adhan, Takbir, Silent)
- Customizable prayer widget: show/hide items, five prayers, 24-hour times, active-prayer color
- Quran reader with search, bookmarks, an exit reminder, and the QuranIndoPak script font
- Steadier Qibla compass
- Simplified Home screen
