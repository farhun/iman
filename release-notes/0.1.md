# Khushu 0.1

First release of this fork.

- Customizable prayer widget: show/hide items, five prayers, 24-hour times, active-prayer indicator color
- Reliable prayer and pre-prayer reminders, with a sound choice for each prayer (Default, Adhan, Takbir, Silent)
- Quran reader with search, bookmarks, exit reminder, and QuranIndoPak script font
- Qibla compass improvements
- Simplified Home screen
